6. Server-side mode (simulated)

Pagination, sorting and filtering are handled by an in-memory mock with a short artificial delay — no real HTTP call is made. The Category column uses headerFilterMode: 'checklist': its funnel icon lists the distinct values of the loaded page, and the picked ones leave as one 'in' filter that the mock applies across all {{ serverTotalCount }} records. resetPage on the event is what sends the query back to page 1.

7. Export and import

CSV and Excel download straight away; PDF opens the browser's print dialog, where "Save as PDF" writes the file. Tick some rows to export only those. Importing parses the file and hands the rows back through (importData) — the grid never modifies data itself.

8. Inline editing against a backend

Add, edit and delete rows. Every commit goes out as an event carrying a done callback, and the row stays in its saving state until that callback answers — set a price of 500 or more to see a rejected write keep the editor open.
